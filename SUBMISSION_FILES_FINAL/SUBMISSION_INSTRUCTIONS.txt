Project Structure:
------------------

omni_align/                 # Core alignment package (6 modules)
├── aligner.py              # Main orchestration (~200 lines)
├── ontology_utils.py       # Loading & preprocessing (~250 lines)
├── matchers.py             # Matching algorithms (~350 lines)
├── scoring.py              # Ensemble scoring (~150 lines)
├── alignment_writer.py     # Output formatting (~100 lines)
└── evaluator.py            # Evaluation metrics (~80 lines)

Main Scripts:
├── run_alignment.py        # CLI for alignment
├── run_evaluation.py       # OAEI evaluation
├── subtask_oa2.py          # Part 1 alignment (OA.2)
└── subtask_oa3.py          # SPARQL queries (OA.3)

Features:
---------

✓ Lexical matching (string similarity)
✓ Structural matching (hierarchy propagation)
✓ Semantic embeddings (sentence-transformers)
✓ Instance matching
✓ TF-IDF candidate generation
✓ Ensemble scoring
✓ Handles 50 to 90,000+ classes
✓ Turtle format output
✓ Alignment API compliant
